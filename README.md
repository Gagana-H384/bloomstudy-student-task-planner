# BloomStudy — Student Task Planner 🌷

A colorful, responsive student planner made with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks with subject, due date, time, priority, and notes
- Edit and delete tasks
- Mark tasks complete and track progress
- Filter tasks by all, pending, and completed
- Search tasks by title, subject, priority, or notes
- Sort by newest, due date, priority, or alphabetically
- Highlights overdue and due-today tasks
- Focus timer with 15, 25, and 45 minute presets
- Light and dark themes
- Export tasks as CSV
- Stores tasks in browser localStorage
- Responsive design for desktop and mobile

## Run locally
1. Download and extract the ZIP.
2. Open the extracted `student-task-planner-plus` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. No build tools or package installation are required.

## Technologies
HTML5, CSS3, JavaScript, localStorage, Blob/CSV export.

## Data note
Tasks are stored in the current browser on the current device. They are not uploaded to a server or synced between devices. Google Fonts are loaded online; the page remains usable without them.
